    Decompress LZ4/LZMA blocks, parse SerializedFileNoUnity CLI / UnityPy-class tool, or Xcode C++ worker
    Retarget platform flag to iOSNoNative bundle rewriter, then repack

    Textures and bundles that need the native steps are copied unchanged here and marked PENDING in the report, so nothing is silently claimed as converted. For full conversion, send the input to a backend worker (Unity CLI + astcenc) and use this page as its front end.

    Run on iPhone

    1. Save index.html to Files (On My iPhone or iCloud Drive).
    2. Easiest: host it on GitHub Pages (upload to a repo, enable Pages in Settings) and open the https link in Safari.
    3. Or tap index.html in Files, then Share → Open in Safari if offered. If you only see source code, use GitHub Pages instead.
    4. Internet is needed once so JSZip can load from the CDN.
    5. Choose a .zip or .unity3d, pick the ASTC block size, toggle the rename option, tap Run, then Download.
